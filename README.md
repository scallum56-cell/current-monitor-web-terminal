# Current Monitor Web Terminal

A browser-based USB/Serial terminal for reading current monitor devices using the Web Serial API.

## How to use

1. Open Google Chrome or Microsoft Edge.
2. Visit the GitHub Pages link for this project.
3. Click "Connect".
4. Select your USB/Serial device from the browser popup.
5. Use the buttons:
   - Send LF
   - Send M?
   - Start Trial (sends M? every 100ms)
   - Stop Trial

Data will appear in the terminal window with "A" appended.

## No installation required
This runs entirely in the browser using the Web Serial API.
